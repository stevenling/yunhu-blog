# 104-二叉树的最大深度

# 题目描述

给定一个二叉树，找出其最大深度。

二叉树的深度为根节点到最远叶子节点的最长路径上的节点数。

说明: 叶子节点是指没有子节点的节点。

示例：
给定二叉树 [3,9,20,null,null,15,7]，

    3
   / \
  9  20
    /  \
   15   7
1
2
3
4
5
6
7
8

返回它的最大深度 3 。

# 思路

递归判断左右子树哪个深度最大。

# 代码

class Solution {
public:
    int maxDepth(TreeNode* root) {
        if(!root)
        {
			return 0;
        }
		else 
			return (1 + max(maxDepth(root->left),maxDepth(root->right)));
    }
};
